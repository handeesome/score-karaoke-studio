# 谱间 v0.1.17 · 跨页续编号与单独移除编号

- 整框模式下，点选框上的数字后按 Backspace，可移除这次演唱的编号和对应打点。原框仍可重新编号，也可撤销此次操作。
- 手动编号按全谱的点击顺序接续。第一页编到 10，第二页编到 11，返回第一页后点击空框或重复点击已有框，都会从 12 接着编。
- 同一个框有多个编号时，数字沿框宽排列，排满后换行。

## 更新方式

已有谱间的 Windows x64 用户可在软件内点击「检查更新」，保存项目后开始更新。也可以关闭软件，将更新 ZIP 的全部内容解压覆盖到原 Pujian.exe 所在目录。

首次使用请先下载安装完整包，再应用此更新。
