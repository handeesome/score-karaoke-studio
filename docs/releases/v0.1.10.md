# 谱间 v0.1.10 · 随时检查更新与更新流程修复

- 新增常驻“检查更新”按钮，随时立即检查新版。发现新版后弹出“保存并开始更新”提示，无需重启软件；没有新版或连接失败时显示检查结果。
- 每次检查与重试更新都会重新读取当前代理设置。先打开软件、后打开 v2rayN，也能直接重新检查或重试；连接成功后才开始下载。
- 修复更新完成后仍显示旧界面的问题。升级后自动加载对应版本的界面，保留已保存的标注和显示偏好，无需手动改名或清除 Cache 文件夹。
- 检查更新连接、下载和安装期间锁定背景操作，包括已展开的“更多工具”和键盘操作；失败后恢复编辑，可再次重试。
- 继续内置 Spleeter 轻量人声模型，无需手动安装；已有模型、歌谱、音频、打点、已完成的人声波形缓存和导出视频保留，视频继续使用原音轨。

## 更新方式

本附件是 Windows x64 累计增量更新包，适用于已有的谱间安装。v0.1.5、v0.1.6、v0.1.8、v0.1.9 可在软件内更新。

旧版本在启动时和每隔 6 小时检查更新。若要立即发现本次更新，请先确保网络或代理可用，再重新打开旧版软件；升级到 v0.1.10 后可直接使用“检查更新”按钮。

也可关闭软件，将 ZIP 的全部内容解压覆盖到原 Pujian.exe 所在目录。不要只复制 EXE，也不要直接在 ZIP 内运行。

首次安装仍需先下载现有完整安装包；本更新 ZIP 不能单独运行。
