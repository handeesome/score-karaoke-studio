# 谱间 v0.1.14 · 整框模式重复使用歌词框

- 整框模式选中歌词框后，可在「乐句设置 → 更多乐句操作」中点击「重复使用选中框」。新乐句追加到结尾，沿用原框的位置，单独打点。
- 重复乐句有独立序号和时间，支持撤销、重做，也可继续重复使用；移动原分区的分隔线时，重复乐句的框同步调整。
- 选中重复乐句可「删除这次重复」，保留原框和其他乐句。重复关系随项目保存，关闭重开后保留。

## 更新方式

本附件是 Windows x64 累计增量更新包，适用于已有的谱间安装。可在软件内点击「检查更新」，发现新版后保存并开始更新。

也可关闭软件，将 ZIP 的全部内容解压覆盖到原 Pujian.exe 所在目录。不要只复制 EXE，也不要直接在 ZIP 内运行。首次安装仍需先下载现有完整包，本更新 ZIP 不能单独运行。

更新保留本机原有项目、音频、模型和人声缓存，继续提供轻量波形及后台原模型静默优化。
