# 谱间 v0.1.15 · 修复歌谱编号变形

- 修复横版、方形或细长歌谱上的「01、02」等编号被压扁或拉长的问题，两种高亮模式均保持正常比例。
- 双击编号时的输入框同步保持正常比例，继续支持修改序号、撤销和重做。
- 重复使用同一歌词框时，编号之间的间距随页面比例调整，缩放后仍保持正常显示。

## 更新方式

本附件是 Windows x64 累计增量更新包，适用于已有的谱间安装。可在软件内点击「检查更新」，发现新版后保存并开始更新。

也可关闭软件，将 ZIP 的全部内容解压覆盖到原 Pujian.exe 所在目录。不要只复制 EXE，也不要直接在 ZIP 内运行。首次安装仍需先下载现有完整包，本更新 ZIP 不能单独运行。

更新保留本机原有项目、编号、打点、音频、模型和人声缓存。
