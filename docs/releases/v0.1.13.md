# 谱间 v0.1.13 · 视频重新生成与命名保存

- 修改乐句、打点、歌谱或画面设置后，导出窗口恢复「生成 MP4 视频」，不再一直显示上一次的导出结果。
- 生成完成后保留「重新生成视频」，无需修改内容也能再次导出。取消保存时，保留上次结果。
- 生成前打开「另存为」窗口，可选择文件夹、查看默认文件名并自行命名。生成时和完成后显示实际保存路径。
- 覆盖同名视频时，先生成完整的新文件，成功后再替换旧视频；生成失败时保留原文件。
- 打开文件夹不再要求视频仍在原位置。打开视频失败时显示实际错误，并提供重新生成入口；未生成完整文件时不会报告成功。
- 本次累计更新也包含歌谱工作区调整：顶部「歌谱」开始新项目；拖入歌谱开始新项目并沿用原音频；只有「更多歌谱」追加页数。「上一页」「下一页」和红色「删本页」集中在更多工具右边，只有多页时显示。

## 更新方式

本附件是 Windows x64 累计增量更新包，适用于已有的谱间安装。可在软件内点击「检查更新」，发现新版后保存并开始更新。

也可关闭软件，将 ZIP 的全部内容解压覆盖到原 Pujian.exe 所在目录。不要只复制 EXE，也不要直接在 ZIP 内运行。首次安装仍需先下载现有完整包，本更新 ZIP 不能单独运行。

更新保留本机原有项目、音频、模型和人声缓存，继续提供轻量波形及后台原模型静默优化。
