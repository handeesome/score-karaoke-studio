# 谱间 v0.1.9 · 编号、谱面颜色与导出改进

- 整框模式按演唱顺序点击编号，数字立即保存；双击数字可直接修改顺序，右上角统一撤销、重做。
- 自动编号支持先唱完第 1 段，再唱第 2、3 段；根据歌词行高度跳过较高的谱行，并提供预览和逐行修正。
- 已编号的框可继续框内竖切；选中分隔线后按 Backspace 或 Delete 合并，原时间段按顺序保留。修复选中线被重复虚线边框遮盖的问题。
- 选择工具统一为手形点击图标，放在工具栏最前面；精简歌谱缩放、页码和常驻提示，时间轴操作集中在一行。
- 「更多工具 → 黑白反色」可把黑底白字谱切为白底黑字；「高亮颜色」支持预设和自定义颜色。设置随歌谱保存，预览与导出一致，原图、编号和打点保留。
- 导出预览支持播放、暂停和拖动定位，音频、画面与文字高亮同步前进。
- 点击「生成 MP4 视频」后先选择保存文件夹，默认打开 Windows「下载」目录。取消选择不会开始生成；完成后显示保存路径，可直接打开视频或文件夹。
- 视频继续直接复制原音轨，不重新编码，不使用分离的人声替换原曲；保留现有音质。

## 更新方式

本附件是 Windows x64 增量更新包，适用于已有的谱间安装；v0.1.5、v0.1.6、v0.1.8 可在软件内检查并更新。也可关闭软件后，将更新包全部内容解压覆盖到原 Pujian.exe 所在目录。

歌谱、音频、打点、已有模型和已完成的人声波形缓存保留。快速人声模型继续内置，离线可用。

首次安装仍需先下载现有完整安装包；本更新 ZIP 不能单独运行。
