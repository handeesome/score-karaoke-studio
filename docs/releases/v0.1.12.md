# 谱间 v0.1.12 · 歌谱导入与分页操作调整

- 顶部「歌谱」一次选择一个 PDF 或图片文件，导入成功后开始新项目，再选择音频。取消选择、导入失败或旧项目保存失败时，保留当前内容。
- 拖入歌谱会开始新项目，沿用原音频，并清空旧标注和打点；同时拖入新音频时，使用新音频。旧项目会先保存。
- 只有「更多工具 → 更多歌谱」会追加到当前项目，可多选文件，保留现有音频、标注和打点。
- 多页歌谱的「上一页」「下一页」放在「更多工具」右边，红色「删本页」紧随其后。只有一页时，翻页和删除按钮均隐藏。
- 删除本页前会确认，移除本页及相关标注和打点，保留其他页与音频，支持撤销。

## 更新方式

本附件是 Windows x64 累计增量更新包，适用于已有的谱间安装。v0.1.10、v0.1.11 可点击「检查更新」，发现新版后保存并开始更新；更早版本可重新打开软件检查新版。

也可关闭软件，将 ZIP 的全部内容解压覆盖到原 Pujian.exe 所在目录。不要只复制 EXE，也不要直接在 ZIP 内运行。首次安装仍需先下载现有完整包，本更新 ZIP 不能单独运行。

更新保留本机原有项目、音频、模型和人声缓存，继续提供轻量波形及后台原模型静默优化。
