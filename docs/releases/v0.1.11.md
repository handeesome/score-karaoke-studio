# 谱间 v0.1.11 · 人声波形优化与多页导入

- 轻量模型完成后立即显示人声波形，可继续播放和打点；后台继续使用原 HTDemucs 模型处理同一音频。
- 原模型处理成功后，直接替换当前波形并更新缓存，不弹提示；处理失败则保留轻量波形，也不显示提示。
- 后台任务独立排队，在 Windows 上以较低优先级运行，默认使用两个 CPU 计算线程。切换音频后，上一首的结果不会覆盖新音频的波形。
- 已有轻量波形缓存也可在后台提升；已完成的原模型波形直接复用。保留现有歌谱、音频、打点和模型，视频继续使用原音轨。
- 时间轴放大或横向滚动后，分离进度、百分比和重试按钮仍固定在可视区域；导入通知显示在时间轴上方。
- 歌谱支持多份 PDF 和图片一起导入、继续追加和手动翻页，追加时保留已有标注。可直接把歌谱与一份音频拖进窗口。
- 修复点击“打点”后空格再次打点的问题；焦点在播放或打点按钮上时，空格控制播放与暂停，长按不会反复切换。

## 更新方式

本附件是 Windows x64 累计增量更新包，适用于已有的谱间安装。v0.1.10 可点击“检查更新”，发现新版后保存并开始更新；更早版本可重新打开软件检查新版。

也可关闭软件，将 ZIP 的全部内容解压覆盖到原 Pujian.exe 所在目录。不要只复制 EXE，也不要直接在 ZIP 内运行。首次安装仍需先下载现有完整包，本更新 ZIP 不能单独运行。

快速人声模型继续内置于更新程序。后台 HTDemucs 使用原有模型；联网版缺少模型时会尝试下载，离线版缺少模型或处理失败时保留轻量波形。
