# 谱间 · 歌谱同步工作台

在本机为 PDF 歌谱中的歌词画框，与音频时间对齐，预览文字高亮，并导出带原音频的卡拉 OK 视频。界面为中文，当前只编辑一首歌，无需账号。

## 功能

- 导入 PDF 歌谱及 MP3、WAV、M4A 或 OGG 音频；需要更换文件时，点击顶部的文件名重新选择。
- 在谱面上自由拖动画框，或用「自动框选」按歌词行和明显留白生成候选框。可竖切、移动、拉伸、复制、合并、调整顺序；同一个歌词框也可供后面重复演唱的乐句使用。
- 播放时点击「打点」或按 Enter 标记起唱、换句和收尾。时间轴显示本机分离的人声波形，支持滚轮缩放、拖动定位，以及拖动或拉伸乐句条微调时间。
- 「自动对齐」以现有歌词框（没有框时先自动框选）为单位，结合谱面文字、音频转写和人声波形低谷给出候选时间。处理时显示阶段和百分比；应用候选不会覆盖已有打点或移动手工框。
- 预览时滚动到当前乐句，并把框内的黑色谱面内容变成橘红色。导出支持 16:9、9:16、4:5、1:1 及自定义画幅，生成 H.264/AAC MP4。
- 编辑状态保存在当前浏览器，刷新页面后可继续；不提供多项目管理。PDF 和音频文件保存在本机后端目录。

## 在 Windows 上运行

先安装 Python 3.11 和 Node.js 20。自动框选、自动对齐还需要安装 Tesseract OCR 及 `chi_sim` 中文语言包；让 `tesseract` 位于 PATH，或安装在 `C:\Program Files\Tesseract-OCR\`。

从 GitHub 克隆或拉取仓库后，双击根目录的 [启动谱间.cmd](启动谱间.cmd)。首次运行会在仓库目录中创建 `.venv`、安装 Python 与前端依赖，并尝试安装人声波形组件，因此需要联网，可能花几分钟；以后双击会直接启动本地服务并打开浏览器。若人声组件安装失败，仍可进入基础界面，稍后按下方命令手动重装。启动文件和 `scripts/` 一起随仓库提交，不要只复制 `.cmd` 文件。

要把入口放到桌面：右键 `启动谱间.cmd` →「显示更多选项」→「发送到」→「桌面快捷方式」。快捷方式仍指向仓库里的启动文件，拉取更新后不用重新制作；更新代码后先运行 [关闭谱间.cmd](关闭谱间.cmd)，再重新启动。关闭文件只会结束启动文件自己开启的后台服务；关闭浏览器标签页本身不会结束后台服务。

另一台电脑的浏览器数据、已导入的 PDF/音频和打点**不会通过 GitHub 同步**；首次打开时需在该电脑重新导入。启动文件不会上传文件。

### 手动运行（开发用）

也可以在项目根目录手动安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
npm ci
```

时间轴的人声波形需要 Demucs，安装在**同一个** Python 虚拟环境中：

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-vocals.txt
```

分别打开两个终端，在项目根目录启动后端和前端：

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

```powershell
npm run dev
```

浏览器打开 <http://127.0.0.1:5173/>。第一次使用人声波形会下载 `htdemucs` 模型并在 CPU 上分离人声，可能需要几分钟；第一次使用自动对齐也会下载 Whisper base 模型。模型缓存后可重复使用。人声分离结果用于时间轴和自动对齐时的换句校准，播放和导出仍使用原音频。未安装 Demucs 时，人声波形无法显示，自动对齐会退回原音频起音校准。

## 基本操作

1. 从顶部工具栏分别选择 PDF 和音频。导出视频时建议使用 MP3；目前导出编码器按 MP3 读取音频时长。
2. 用「添加标注」从框的一角拖到对角，自由确定宽和高；也可以先用「自动框选」生成候选，再逐个核对。单击谱面上的框即可选中，拖动框内移动，拖动边线或四角调整大小。
3. 如需把一框分成两句，使用「竖切成框」。切割位置只决定两个框的边界，不代表拍点；已有打点会尽量保留，请检查新句时间。可单击框角的序号或在右侧检查器中调整乐句顺序。
4. 播放音频，在第一句起唱时打点；之后每次换句再打一次，最后一句结束时打收尾点。已有句子的打点不会因为继续打点而自动清空。需要微调时，可拖动时间轴上的乐句条或其两端，也可在检查器中改时间。
5. 重复唱同一句时，选中谱面上已有的框，点击检查器中的「重复使用选中框」，再给新乐句打点。多选后可一次重复使用多个框。
6. 点击「导出视频」检查标注、预览画面并选择画幅。导出的文件保存在 `backend/exports/`，也可从界面下载。

在谱面空白处拖框或按住 Shift 点击可多选；选中的乐句可合并。「重新标注」会清空乐句和打点，但保留当前导入的文件。Ctrl+Z 可撤销，Ctrl+Shift+Z 或 Ctrl+Y 可重做；选中乐句时可按 Delete 或 Backspace 删除。

## 数据与限制

- 歌谱和音频不会上传到云端服务。首次下载模型需要联网；音频分析、OCR、预览和视频渲染在本机进行。
- 浏览器使用 `localStorage` 保存当前编辑状态；后端把导入文件及渲染页面放在 `backend/projects/`、`backend/media/`，把视频放在 `backend/exports/`。这些目录以及模型缓存不纳入 Git。若清理浏览器数据或上述目录，编辑状态可能无法恢复。
- PDF 最多 100 页，页面以 240 DPI 渲染。自动框选和自动对齐是候选结果，扫描质量、重复歌词和伴奏都会影响准确度；导出前请核对时间与框的位置。
- 高亮作用于框内的黑色图像内容，若框中包含音符或其他黑色图形，它们也会变色。人声分离也可能留下少量伴奏或漏掉较弱的和声。
