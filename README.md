# 谱间 · 歌谱同步工作台

本地运行的中文歌谱卡拉 OK 视频工具。导入 PDF 乐谱和音频后，可按乐句画区域、连续播放打点、预览滚动与高亮，并导出带原音频的 H.264/AAC MP4。

## 功能

- 只处理当前一首歌：首次选择 PDF 乐谱和音频，之后可分别替换；不需要新建、切换或手动保存项目。刷新页面可恢复当前编辑。
- PDF 按 240 DPI 渲染为页面图片，保留原 PDF 与页面尺寸信息。
- MP3、WAV、M4A、OGG 播放与时间定位，支持 0.5×、0.75×、1×、1.25×。
- 时间轴默认用 Demucs 在本机分离出人声音轨，再从人声计算音量波形和峰值；点击波形可跳转，已标注乐句叠加显示。可切换查看原音频波形。分离结果只用于时间轴，播放和导出仍使用原音频。
- 归一化页面坐标标注；点击歌谱上的框即可选中，拖动框可移动，拖动四边或四角的控制点可调整大小，也可复制和删除乐句。
- PDF 和 MP3 文件按钮位于乐谱工具栏，点击即可重新选择；文件名不显示后缀。乐谱默认按工作区宽度自动适配，可用缩放按钮微调，点击「自动适配」恢复自动模式。
- 「添加标注」从歌词行左上角向右拖出一行；单击时也以点击处为左上角生成默认宽度。添加后保持在该模式，可连续画下一行。「竖切成框」点击已有框内的位置，会把它分成左右两个独立标注，可继续切割、分别调整时间；Ctrl+Z 可撤销切割。
- 「自动框选」只分析乐谱图像：先找歌词行，再按明显大于普通字距的横向留白拆成候选框。先预览、勾选，再应用；默认保留已有标注并补充未覆盖区域。新框的时间是占位值，需继续打点或使用自动对齐校准。
- 播放时按「打点」或 Enter 记录起唱、换句和收尾时间。
- 「自动对齐」在本机识别扫描乐谱歌词和 MP3 唱词，按歌词顺序结合音频起音估计乐句时间。先显示候选文字、时间、可信度与试听入口，勾选后才应用；已有位置相符的手工画线会保留，可撤销。
- 播放和导出时只将当前进度内的黑色谱面文字变为橘红色，不再给歌词铺半透明背景。框选区域若包含音符或其他黑色图形，它们也会随之变色。
- Ctrl+Z 撤销、Ctrl+Shift+Z / Ctrl+Y 重做；输入框聚焦时不触发快捷键。
- 选中标注后按 Delete 删除该标注及关联打点；输入时间时，Delete 仍只删除输入框中的文字。
- 左侧「重新标注」可在确认后清空当前歌曲的乐句与打点，保留导入的乐谱和音频；清空后可立即按 Ctrl+Z 恢复。
- 播放预览自动滚动到当前乐句。导出预览与视频导出共用后端画面渲染与取景计算。
- 提供 16:9、9:16、4:5、1:1 和自定义画幅。帧在内存中生成并管道传给 FFmpeg，不产生逐帧 PNG 文件。

## 启动

首次安装依赖：

```powershell
npm install
python -m pip install -r backend/requirements.txt
```

自动对齐还需要安装 Tesseract OCR 及 `chi_sim` 中文语言包，并让 `tesseract` 位于 PATH（Windows 也会检查 `C:\Program Files\Tesseract-OCR\tesseract.exe`）。首次使用会将本地 Whisper base 模型缓存到 `reference/models`；模型尚未缓存时需要联网下载一次。本项目的示例环境已经缓存模型。

### 人声波形

默认的人声波形需要额外安装 Demucs。已创建 `.venv` 时，在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install --no-cache-dir -r backend/requirements-vocals.txt
```

安装后重启后端。首次提取会下载 `htdemucs` 模型并在本机用 CPU 分离歌曲，可能需要几分钟；同一音频之后从 `reference/vocals` 读取缓存。若尚未安装，可在时间轴点击「查看原音频」临时切换。分离结果可能保留少量伴奏或漏掉较弱的和声，所以打点时仍应试听。

在两个终端分别启动：

```powershell
python -m uvicorn backend.main:app --reload --port 8000
```

```powershell
npm run dev
```

打开 Vite 显示的本地地址。前端为 React、Vite、TypeScript；后端为 FastAPI、PyMuPDF、Pillow 和 FFmpeg。

## 坐标与同步

标注的 `x/y/width/height` 均相对于原始 PDF 页面的可视范围，数值为 0 到 1 的比例；这些数值仅用于内部保存，编辑界面通过鼠标移动和缩放框。缩放乐谱不会改变保存坐标。每个框有独立的起止时间，框内文字按该时间线性高亮。

切割时，新框暂按原框的时间范围和切割位置分配起止时间，仅作为待校准的初始值，并不表示节拍。若已有连续打点，切割会清空旧打点，以免标记对应到错误的框；可随后重新打点或直接调整起止时间。旧版保存在框内的竖线会在载入时转换成独立标注框。

自动对齐给出的时间是候选值：伴奏可能掩盖人声停顿，扫描件也可能有 OCR 错字。预览列表会将未找到可靠文字匹配的行标为「待核对」。重复唱同一段歌词时，可能还需在工作台复制对应区域并校准时间。
